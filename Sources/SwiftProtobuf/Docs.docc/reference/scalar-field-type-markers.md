# Scalar field-type markers

Generated code uses these types as the `FieldType` witness for a field's Swift type; you shouldn't need to reference them directly.

## Topics

### Numeric types

- ``ProtobufInt32``
- ``ProtobufInt64``
- ``ProtobufUInt32``
- ``ProtobufUInt64``
- ``ProtobufSInt32``
- ``ProtobufSInt64``
- ``ProtobufFixed32``
- ``ProtobufFixed64``
- ``ProtobufSFixed32``
- ``ProtobufSFixed64``
- ``ProtobufFloat``
- ``ProtobufDouble``

### Other types

- ``ProtobufBool``
- ``ProtobufString``
- ``ProtobufBytes``
